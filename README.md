# 钟启轩 / AXUAN 个人作品集

React + Vite，面向 PC 展示，最大版心 1700px

## 当前设计

- 配色恢复为原版暗色风格：炭黑 `#101111`、深色首页 `#0b0e0c`、灰白 `#edf2ea`、浅绿点缀 `#d0ed90`
- 首页采用基于本人照片生成的三渲二动漫肖像，右侧人物、左侧标题与按钮，人像区域没有能力标签
- 桌面端双眼随鼠标微动，通过平面图像的局部纹理位移实现，无三维模型或 Three.js 依赖
- 关于我默认展示有背景的原照片，悬停切换为白衬衫照片，离开后恢复，支持键盘及触屏切换
- 标题、正文、项目详情和页面描述不使用句号，邮箱与链接保留必要的点号
- 保留 GSAP 入场、滚动效果、首页动态图标与项目详情弹窗，七支视频与四组视觉方法作品分区展示
- 《高欢前传》06、07、08 在作品区叠成一组，鼠标移入后以手牌扇形展开，点击后在统一系列栏内切换播放与简介
- 尊重系统的减少动态效果设置

## 预览

当前地址：http://127.0.0.1:5314/

本机双击 `打开作品集.cmd` 打开正式预览，修改代码时使用 `启动开发预览.cmd`

本地服务会随关机或启动窗口关闭而停止，再次双击入口即可恢复，网站文件不会因此丢失

图片、字体和视频均存储在本地，依赖已安装的本机可以离线观看

```sh
pnpm install
pnpm dev
pnpm build
```

构建输出为 `dist/`，当前没有对外发布

## 修改入口

- `src/main.jsx`：介绍、经历、项目、能力、联系方式及交互
- `src/Portrait.jsx`、`src/eye-motion.js`：动漫肖像与双眼微动，离开首页或切换页面后停止渲染
- `src/AboutPortrait.jsx`：两张有背景照片的交互切换
- `src/video-projects.js`：新增视频的介绍、个人职责、模型背景及来源
- `src/styles.css`、`src/portrait.css`、`src/anime.css`：暗色主题、电影感首页与响应式布局
- `public/media/axuan-anime-hero.webp`：首页动漫肖像
- `public/media/axuan-about-default.webp`、`axuan-about-hover.webp`：关于我默认与悬停照片
- `palette-reference.json`：当前暗色主题的主要颜色
- `../portrait/anime/`：生成的高清原图、提示词与说明，旧去底素材保留在上级目录
- `../avatar/archived-site-purple/`：先前三维版本归档，不对网页提供
